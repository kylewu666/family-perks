家享 · 家庭会员权益合集

零依赖静态网站，无需 npm 安装或构建。请通过 Web 服务访问，不要直接双击 index.html。

本机预览
在此目录运行 python3 -m http.server 8080，然后打开 http://localhost:8080。

GitHub Pages
将此目录内容上传到仓库根目录，在仓库 Settings > Pages 选择从分支部署及根目录。所有资源使用相对路径，支持仓库子路径。等待生成 HTTPS 地址。

Vercel
导入包含这些文件的仓库，Framework 选择 Other，不设置构建命令，发布目录指向这些文件所在目录。

连接现有 Supabase
1. 在项目 SQL Editor 执行 schema.sql（首次执行一次）。
2. 在 Authentication 中创建一个家庭共用邮箱密码账号。两台手机使用同一账号即可共享勾选。老金和老武是会员归属分类，不是两个登录账号。
3. 网站设置页填写项目 URL 与公开 anon/publishable API key，然后登录。禁止使用 service_role/secret key。
4. 登录从云端加载记录，本机体验勾选不会自动导入云端。登录凭证只保存在当前页面内存，刷新后需重新登录。
5. 勾选即时写入云端；另一台设备重新登录即可取得最新状态，暂未实现实时订阅。
6. 离线/写入失败时仅保存到本机，不自动补传。重新登录以云端记录为准。

修改真实会员
编辑 app.js 顶部 memberships 数组，填写真实会员名称、归属、分类和权益。id 和权益 id 是保存记录的标识，使用后应保持稳定。
网站设置页可以填写每个会员的 HTTPS 官方会员中心链接。各手机的链接配置独立保存在本机；也可以在 app.js 的初始配置中集中维护。
当前四个会员及八项权益均为示例，不代表真实购买或官方承诺。

PWA
提供 manifest、192/512 图标、Service Worker 和 iOS 桌面配置。
iPhone 使用 Safari 的分享菜单添加到主屏幕。华为在兼容浏览器菜单中添加到桌面/安装应用。实际入口由系统和浏览器决定。
正式网址必须 HTTPS，首次联网打开后可离线访问页面。数据库请求不会被离线缓存。
更新静态文件时同时更新 sw.js 的 CACHE 版本，避免旧缓存长期残留。
